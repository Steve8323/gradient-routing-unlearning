Random-interconnected gradient routing: does scatter-then-prune delete a capability?

Question (your idea): tag a random, interconnected ~50% of weights as "waste", route forget-class learning into them, block retain-class learning from them, and prune the waste at test time to delete the forget capability. Does it work without a clean structural region?

Setup: MNIST, MLP 784-256-256-10, forget={0..4}, retain={5..9}, 6k train / 2k test, 8 epochs, CPU. 3 seeds. Routing on the two hidden weight matrices. Chance ≈ 0.20 (5 classes). Independently replicated by a second agent with separate code (forget→0.0, retain→0.21 — matches).

What the experiment found

  1. The deletion is real, not a pruning artifact. Pruning the same random 50% on a normally-trained net (control) leaves forget at 0.93 and retain at 0.87 — nets shrug off random 50% pruning. So routing's forget→0.0 is genuine localization: the forget capability really was concentrated into the prunable weights.
  2. Naive random routing is a sledgehammer, not a scalpel. It deletes forget (0.0) but collapses retain (0.20 ≈ chance). The control proves this is not the prune's fault (control retain survives at 0.87) — it's co-adaptation: main weights learn to depend on waste activations during training, so zeroing waste pulls the rug out.
  3. Ablation-aware training makes it a true scalpel. Train the retain loss on the already-pruned net so main can't depend on waste → forget 0.0, retain 0.95, even with random scattered weights. Clean targeted deletion with a random interconnected mask.
  4. Absorption is real and strong — in the naive version. Even with 75% of forget data mislabeled as retain (only 25% correctly routed), pruning still deletes all forget (forget_pruned = 0.0); it only returns at 100% mislabel. A minority correctly-routed seed absorbs the rest.
The tradeoff this surfaced (the interesting bit): the ablation-aware fix that preserves retain destroys absorption — at 50% mislabel, forget_pruned jumps from 0.0 to 0.92. Both effects are the same knob: does main's training see the waste region? If it does → main co-adapts (retain collapses on prune) and waste preempts main from learning mislabeled forget (absorption). If it doesn't (ablation-aware) → no co-adaptation (clean prune) and no preemption (mislabeled forget leaks into main, absorption dies). Co-adaptation-collateral and absorption are two faces of one coin.

Caveats

Tiny model (sub-1M params), MNIST, a 5-vs-5 class split as a "capability" proxy; absorption in the naive condition is partly entangled with the co-adaptation collapse (cleanest absorption readout is structural, where retain partly survives: at 75% mislabel, forget 0.0 / retain 0.84). p_waste fixed at 0.5. These are existence-proof dynamics on a toy, not a frontier claim — but they reproduce the SGTM "robust to ~50% label noise" finding and expose a mechanism-level tension worth testing at scale.
